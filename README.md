# 职达助手

Windows 本地求职助手：上传简历、整理求职画像、推荐岗位、审核并发起沟通。

[下载最新正式版](https://github.com/GeTan424000/zhida-releases/releases/latest)

## 使用

1. 下载最新发布中的 Windows ZIP 安装包，完整解压到自己的文件夹。
2. 双击 `启动职达助手.exe`。支持 Windows 10/11 64 位，需要 Microsoft Edge，无需另装 Node.js。
3. 上传 PDF、DOCX、TXT 或 Markdown 简历，核对本地规则提取的画像，设置求职偏好。
4. 登录自己的招聘平台账号，确认平台简历与当前版本一致，再推荐岗位、审核并投递。

当前版本支持 BOSS 直聘和猎聘；智联招聘尚未接入。发起沟通和发送附件分别核验、分别记录；上传到助手的文件用于分析，不会自动替换平台简历。

## 软件更新

在软件的“软件更新”中检查、下载并安装新版。安装前停止投递任务，更新会保留本机 `data` 文件夹中的简历、登录状态和记录。

最早的 1.0.0 没有更新入口，需要先关闭软件、手动覆盖程序文件并保留原 `data` 文件夹，之后才能在线更新。

## 这个仓库发布什么

本仓库用于分发程序安装包、签名更新清单 `latest.json` 和校验文件 `SHA256SUMS.txt`。简历、账号登录状态、个人投递记录和发布私钥不上传到此仓库。

向他人分享时请转发发布页面或原始 ZIP，不要转发自己已经使用过的整个程序目录。
